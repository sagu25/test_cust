🤖 The 3 Agents — Each has a different role
🔍
Agent 1 — The Tester
Test Agent
agents/test_agent.py
  • Reads each document one at a time
  • Asks LLM to create 3 test questions per document
  • Questions must have explicit answers in the text
  • Prioritises questions that scored poorly before
  • Fires all questions to Custom Agent in parallel
  • Sends results to Orchestrator

Analogy: The teacher who writes the exam
💬
Agent 2 — The Subject (Being Tested)
Custom Agent
custom_agent_connector.py
  • Receives a question from Test Agent
  • Calls Retriever → gets top 6 relevant chunks
  • Builds a 2-step prompt for the LLM:
    • Step 1: Quote the relevant passage from chunks
    • Step 2: Answer using ONLY that quote
  • If LLM says "no relevant sentence found" → returns "not covered"
  • Returns final answer back to Orchestrator

Analogy: The student taking the exam
⚖️
Agent 3 — The Judge
Evaluator
agents/evaluator.py
  • Receives every question + answer pair
  • Runs 4 different scoring methods
  • First-ever answer → stored as Golden Answer
  • All future answers compared against Golden Answer
  • Flags answers that contradict each other
  • Saves scores to database for dashboard

Analogy: The examiner who grades the paper

Primary Mode
Embedding Mode (Azure)
rag_app/retriever.py — text-embedding-3-small
  • Converts text to meaning vectors
  • Understands that "training expenses" = "learning budget"
  • Semantic search — matches by meaning, not keywords
  • Activated when Azure embedding key is set in .env

Fallback Mode
TF-IDF Mode (Keyword)
rag_app/retriever.py — scikit-learn
  • Matches by exact keywords
  • Includes synonym expansion (training → learning)
  • Free — no API key needed
  • Used when Azure embedding is not configured
📏 4-Layer Evaluation — How every answer is scored
1
Factual Anchor
🔢
Code-based check.

Extracts all numbers and dates from the answer.

Checks if they appear in the retrieved document chunks.

Score 1.0 = all facts from document
Score 0.0 = facts made up by LLM
2
Golden ROUGE-L
🏆
Math-based comparison.

First answer ever = stored as Golden Answer (ground truth).

All future answers compared against it using ROUGE-L score.

Score 1.0 = identical to golden
Score 0.0 = completely different
3
LLM Judge
⚖️
AI-powered scoring.

Sends question + answer + context to LLM which scores:

• Faithfulness — supported by context?
• Relevancy — actually answers the question?
• Completeness — is it a full answer?

Overall = average of 3 scores
4
Consistency
🔄
Tracked over multiple cycles.

Same question asked repeatedly across many runs.

Are all answers saying the same facts?

✅ Consistent = same meaning each time
⚠️ Flagged = answers contradict each other
🤖 Test Agent vs Custom Agent — Are they the same?
Property Test Agent (Agent 1) Custom Agent (Agent 2)
Role The Tester — creates and asks questions The Subject — receives and answers questions
Input Document text from the document store A question from the Test Agent
Output A list of test questions An answer to the question
Uses RAG? No — reads documents directly to write questions Yes — searches documents to find answers
Uses LLM? Yes — to generate good questions from document text Yes — to answer based on retrieved chunks only
Analogy 📝 Teacher writing the exam paper 🎓 Student sitting the exam
Same work? ❌ NO — completely different roles. One asks, the other answers.
