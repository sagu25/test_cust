Step 2 — Agent 1
Test Agent Generates Questions
The Test Agent reads each document directly and asks an LLM to create test questions. Every question must have an explicit answer in the document text — no guessing.

Step 4 — Agent 2
Custom Agent Answers the Question
The retrieved chunks are sent to GPT-4.1 with a special 2-step prompt that forces the model to QUOTE from the document before answering — preventing it from using its own knowledge.

📝 Prompt sent to GPT-4.1

DOCUMENT EXCERPTS:

[Training Policy]: "Employees are eligible for a learning budget of ₹1,500 per year."

QUESTION: What is the annual learning budget per employee?

STEP 1 — Quote the most relevant passage from the excerpts above.

STEP 2 — Using ONLY what you quoted, write a clear answer. Do not use your own knowledge.

🤖
GPT-4.1 RESPONSE
STEP 1 — Quote:
"Employees are eligible for a learning budget of ₹1,500 per year."

STEP 2 — Answer:
The annual learning budget per employee is ₹1,500.
✅ ANSWER PASSED VERIFICATION
The answer "₹1,500" comes directly from the quoted text — not from GPT's own training knowledge. No hallucination.

That's the Full Cycle
In 2 minutes, the system tested your AI agent, scored 3 answers across 4 dimensions, caught any hallucinations, and showed results on the dashboard. Then it repeats — forever.
⏰
Orchestrator
Wakes up every 2 minutes and runs the whole pipeline automatically. No human needed.
🔍
Test Agent (Agent 1)
Reads documents and creates questions that MUST have explicit answers. Like a teacher writing an exam.
💬
Custom Agent (Agent 2)
The AI being tested. Searches documents using embeddings, quotes before answering. Like a student sitting the exam.
⚖️
Evaluator (Agent 3)
Scores every answer across 4 layers — facts, golden comparison, LLM judgment, and consistency. Like the examiner.
The Key Insight
Test Agent and Custom Agent are NOT the same.
One asks questions. The other answers them.

Together, they create a fully automated quality assurance loop that runs continuously — catching hallucinations, measuring consistency, and tracking improvement over time.
